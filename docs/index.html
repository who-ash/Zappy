Frequently asked
questions

What do I need to run it?

Node 22 or later and your web app running locally. The first run installs Playwright's Chromium, and the first render downloads Remotion's headless Chrome (about 140 MB).

Does it record my production site?

No. Point it at a local or staging dev server with demo data. A before: command can reset that data before each recording.

Which voices can I use?

Sarvam (Bulbul v3) or OpenAI (gpt-4o-mini-tts), using your own API key. Set tts.provider: none for a captions-only video with no key at all. Clips are cached, so a re-render only pays for lines you changed.

What about flows behind a login?

Run zappy login admin <url> once and sign in by hand. The session is saved locally (git-ignored), and specs use it with auth: admin.

Can it make vertical videos for social?

Yes. Set style: promo with format: vertical or square for a short, music-led clip with headlines and stickers.

How do I keep private data out of the video?

Use fictional demo data where you can. For anything else, list CSS selectors under blur and those elements are blurred on every page before capture.

Is it free?

Yes, MIT licensed. The only cost is TTS usage on your own key, if you turn voice on.
